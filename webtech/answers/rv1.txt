=== RV1 Q3
<table class="tbl"><tr><th>Selector</th><th>Syntax</th><th>Selects</th></tr>
<tr><td>Descendant</td><td><code>div p</code></td><td>every p <b>inside</b> the div, at any depth</td></tr>
<tr><td>Adjacent sibling</td><td><code>h2 + p</code></td><td>the <b>one</b> p that comes <b>immediately after</b> an h2, with the same parent</td></tr>
<tr><td>General sibling</td><td><code>h2 ~ p</code></td><td><b>all</b> p elements that come after the h2, with the same parent</td></tr></table>
<p>Descendant looks <b>down</b> the tree (children, grandchildren); sibling selectors look <b>sideways</b> at elements sharing the same parent.</p>
```run html
<style>
  div p  { color: blue; }
  h2 + p { background: yellow; }
  h2 ~ p { font-style: italic; }
</style>
<div>
  <h2>Heading</h2>
  <p>Right after h2: adjacent and general sibling, and a descendant of div</p>
  <p>Later sibling: general sibling and descendant</p>
</div>
```

```css
.breaking-news {
  position: fixed;     /* placed relative to the browser window, not the page */
  top: 0;              /* stuck to the very top */
  left: 0;
  width: 100%;         /* full width */
  z-index: 1000;       /* stays above other content */
  background: red;
  color: white;
  padding: 10px;
}
body {
  padding-top: 45px;   /* so the banner does not cover the first lines of the page */
}
```
<p><code>position: fixed</code> removes the banner from the page flow and fixes it to the viewport, so it stays at the top however far the user scrolls.</p>

=== RV1 Q8
```run html
<!DOCTYPE html>
<html>
<head>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
</head>
<body>
  <h3>Grade Calculator</h3>
  Marks (out of 100): <input type="number" id="marks">
  <button id="calc">Calculate</button>
  <p id="result"></p>

  <script>
    $(document).ready(function () {
      $("#calc").click(function () {
        var m = parseFloat($("#marks").val());
        if (isNaN(m) || m < 0 || m > 100) {
          $("#result").text("Enter marks between 0 and 100").css("color", "red");
          return;
        }
        var grade, status;
        if (m >= 90)      { grade = "A"; status = "Excellent"; }
        else if (m >= 75) { grade = "B"; status = "Good"; }
        else if (m >= 50) { grade = "C"; status = "Average"; }
        else              { grade = "F"; status = "Fail"; }
        $("#result").text("Grade: " + grade + " (" + status + ")").css("color", grade == "F" ? "red" : "green");
      });
    });
  </script>
</body>
</html>
```
<p><code>$("#marks").val()</code> reads the input, the if-else ladder checks from the highest band down, and <code>.text()</code> / <code>.css()</code> show the result. Try 92, 80, 60 and 30.</p>

<p><code>text-decoration: line-through</code> draws a line <b>through the middle</b> of the text (used for old prices, completed tasks). <code>text-decoration: none</code> <b>removes</b> any decoration, most often the underline of links: <code>a { text-decoration: none; }</code>.</p>

=== RV1 Q13
<p>Background colour: add <code>background-color: #f1f8e9;</code> to the card (as in Q10). The background fills the content <b>and the padding</b> area, but not the margin.</p>
<ul>
<li><b>Content</b>: the text and image area; its size is set by <code>width</code>/<code>height</code>.</li>
<li><b>Padding</b>: space between the content and the border. Adds to the card's size, takes the background colour, and makes the content look less cramped.</li>
<li><b>Border</b>: the line around the padding. Its thickness adds to the size.</li>
<li><b>Margin</b>: transparent space <b>outside</b> the border, separating the card from other elements. It does not change the card's visible size, only the space it takes.</li>
</ul>
<p>Final visible width = width + left/right padding + left/right border (250 + 30 + 4 = 284px in Q10). <code>box-sizing: border-box</code> makes <code>width</code> include padding and border instead.</p>
