<p>A <b>callback</b> is a function passed as an argument to another function, which calls it later: when a task finishes, an event happens, or for each item.</p>
```js
function download(file, done) {
  console.log("Downloading " + file + "...");
```

=== RJS Q36
<p>The <b>DOM</b> is a tree-shaped, object version of the HTML page that the browser builds when it loads the page. <code>document</code> is the root; each element is a node with parent, child and sibling nodes, and attributes and text are nodes too.</p>
<p><b>Why it matters</b>: JavaScript cannot touch the HTML text file. Everything dynamic is done through the DOM:</p>
<ul><li><b>Find</b> elements: <code>getElementById</code>, <code>querySelector</code>, …</li>
<li><b>Change</b> content and style: <code>innerHTML</code>, <code>style</code>, <code>classList</code>, <code>setAttribute</code></li>
<li><b>Add and remove</b> elements: <code>createElement</code>, <code>appendChild</code>, <code>remove</code></li>
<li><b>React to the user</b>: <code>addEventListener("click", …)</code></li></ul>
<p>The page updates without reloading, which is what makes interactive pages (form validation, live scores, to-do lists) possible; jQuery and React are built on top of the DOM. See May24 Q19a for the access methods with a running example.</p>

=== RJS Q40
<p>An <b>event</b> is something that happens on the page: a click, key press, mouse move, form submit, page load. <b>Event handling</b> means attaching a function (the <b>handler</b> or listener) that runs when the event fires.</p>
<p><b>Three ways to attach a handler:</b></p>
```run html
<button onclick="alert('1. inline attribute')">Inline</button>
<button id="b2">Property</button>
<button id="b3">addEventListener</button>
<div id="outer" style="padding:10px;background:#eef;margin-top:8px">outer div
  <button id="inner">inner button (bubbling)</button>
</div>
<p id="log"></p>
<script>
  // 2. DOM property: only one handler per event
  document.getElementById("b2").onclick = function () { alert("2. onclick property"); };

  // 3. addEventListener: many handlers allowed, can be removed
  document.getElementById("b3").addEventListener("click", function (e) {
    alert("3. addEventListener; event type = " + e.type);
  });

  // bubbling: the click on the inner button also reaches the outer div
  document.getElementById("outer").addEventListener("click", function () {
    document.getElementById("log").innerHTML += "outer got the click<br>";
  });
  document.getElementById("inner").addEventListener("click", function (e) {
    document.getElementById("log").innerHTML += "inner clicked<br>";
    // e.stopPropagation();   // would stop it reaching the outer div
  });
</script>
```
<ul><li><b>Event object</b> <code>e</code>: details of the event (type, target, key pressed); <code>e.preventDefault()</code> stops the default action (e.g. a form submitting).</li>
<li><b>Propagation</b>: an event <b>bubbles</b> up from the target to its ancestors; <code>stopPropagation()</code> stops it.</li>
<li>Common events: click, dblclick, mouseover, mouseout, keydown, keyup, change, input, submit, focus, blur, load.</li></ul>
<p><b>How events improve interactivity</b>: the page reacts immediately to what the user does (validation messages while typing, menus opening, scores updating) without reloading or contacting the server.</p>

```run html
  <style>
    body { font-family: Arial; text-align: center; }
    .t { display: inline-block; width: 170px; margin: 8px; padding: 10px; border: 2px solid #0277bd; border-radius: 10px; }
    .p { font-size: 40px; font-weight: bold; }
    #msg { font-weight: bold; color: #2e7d32; min-height: 1.3em; }
  </style>
</head>
<body>
  <h2>Volleyball Score Tracker</h2>
  <p>Set <span id="set">1</span> | Sets won: A <span id="setsA">0</span> - <span id="setsB">0</span> B</p>
  <div class="t"><h3>Team A</h3><div class="p" id="a">0</div><button onclick="point('A')">+1 Point</button></div>
  <div class="t"><h3>Team B</h3><div class="p" id="b">0</div><button onclick="point('B')">+1 Point</button></div>
  <p id="msg"></p>
  <button onclick="reset()">Reset Match</button>

  <script>
    var pts = { A: 0, B: 0 }, sets = { A: 0, B: 0 }, setNo = 1;

    function point(t) {
      if (sets.A == 3 || sets.B == 3) return;          // match over
      pts[t]++;
      var o = t == "A" ? "B" : "A";
      var target = setNo == 5 ? 15 : 25;               // 5th set is played to 15
      if (pts[t] >= target && pts[t] - pts[o] >= 2) {  // win the set by 2 clear points
        sets[t]++;
        document.getElementById("msg").innerHTML = "Team " + t + " wins set " + setNo;
        if (sets[t] == 3) document.getElementById("msg").innerHTML = "Team " + t + " wins the match!";
        else { setNo++; pts = { A: 0, B: 0 }; }
      }
      show();
    }

    function show() {
      document.getElementById("a").innerHTML = pts.A;
      document.getElementById("b").innerHTML = pts.B;
      document.getElementById("setsA").innerHTML = sets.A;
      document.getElementById("setsB").innerHTML = sets.B;
      document.getElementById("set").innerHTML = setNo;
    }

    function reset() {
      pts = { A: 0, B: 0 }; sets = { A: 0, B: 0 }; setNo = 1;
      document.getElementById("msg").innerHTML = "";
      show();
    }
  </script>
</body>
</html>
```
<p>Volleyball rules are built in: a set is won at 25 points (15 in the fifth) with a 2-point lead, and the match goes to the first team to win 3 sets. The display updates after every rally.</p>

```run html
  <script>
    var btn = document.getElementById("toggle");

    function apply(dark) {
      document.body.classList.toggle("dark", dark);
      btn.textContent = dark ? "☀️ Light Mode" : "🌙 Dark Mode";
    }

    // remember the choice between visits
    var saved = null;
    try { saved = localStorage.getItem("theme"); } catch (e) {}
    apply(saved == "dark");

    btn.addEventListener("click", function () {
      var dark = !document.body.classList.contains("dark");
      apply(dark);
      try { localStorage.setItem("theme", dark ? "dark" : "light"); } catch (e) {}
    });
  </script>
</body>
</html>
```
<ul><li>All dark colours live in CSS under a <code>.dark</code> class; JavaScript only adds or removes that class with <code>classList.toggle</code>.</li>
<li><code>transition</code> makes the switch smooth; the button label changes with the mode.</li>
<li><code>localStorage</code> remembers the choice, so the page opens in the same theme next time.</li></ul>

```run html
<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: Arial; padding: 10px; }
    .filters button { margin: 2px; padding: 5px 12px; }
    .filters button.on { background: #2e7d32; color: white; }
    .item { display: flex; justify-content: space-between; align-items: center; border-bottom: 1px solid #ddd; padding: 8px 0; width: 380px; }
    #cart { margin-top: 12px; padding: 10px; background: #f1f8e9; width: 360px; }
  </style>
</head>
<body>
  <h2>Spice Garden Menu</h2>
  <div class="filters">
    <button class="on" onclick="filter('All', this)">All</button>
    <button onclick="filter('Starter', this)">Starters</button>
    <button onclick="filter('Main', this)">Main Course</button>
    <button onclick="filter('Dessert', this)">Desserts</button>
  </div>
  <div id="menu"></div>
  <div id="cart"><b>Your order:</b> <span id="items">empty</span><br><b>Total: Rs. <span id="total">0</span></b></div>

  <script>
    var menu = [
      { name: "Paneer Tikka", type: "Starter", price: 220 },
      { name: "Veg Spring Roll", type: "Starter", price: 160 },
      { name: "Chicken Biryani", type: "Main", price: 280 },
      { name: "Butter Naan with Dal", type: "Main", price: 190 },
      { name: "Gulab Jamun", type: "Dessert", price: 90 },
      { name: "Ice Cream Sundae", type: "Dessert", price: 140 }
    ];
    var order = [];

    function show(list) {
      var html = "";
      list.forEach(function (m) {
        html += '<div class="item"><span>' + m.name + " - Rs. " + m.price + '</span>' +
                '<button onclick="addToOrder(\'' + m.name + '\')">Add</button></div>';
      });
      document.getElementById("menu").innerHTML = html;
    }

    function filter(type, btn) {
      document.querySelectorAll(".filters button").forEach(function (b) { b.classList.remove("on"); });
      btn.classList.add("on");
      show(type == "All" ? menu : menu.filter(function (m) { return m.type == type; }));
    }

    function addToOrder(name) {
      order.push(menu.find(function (m) { return m.name == name; }));
      document.getElementById("items").innerHTML = order.map(function (m) { return m.name; }).join(", ");
      document.getElementById("total").innerHTML = order.reduce(function (t, m) { return t + m.price; }, 0);
    }

    show(menu);
  </script>
</body>
</html>
```
<p>The menu is an array of objects that JavaScript renders into the page; category buttons <code>filter()</code> it, and "Add" puts an item into the order and recalculates the total with <code>reduce</code>.</p>
