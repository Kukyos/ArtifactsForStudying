=== RPQ Q5
```run html
<!DOCTYPE html>
<html>
<head>
  <style>
    #bill { margin-top: 12px; padding: 10px; border: 1px solid #999; width: 280px; display: none; }
  </style>
</head>
<body>
  <h3>Electricity Bill Calculator</h3>
  <form onsubmit="return false;">
    Consumer Name: <input type="text" id="cname" required><br><br>
    Units Consumed: <input type="number" id="units" min="0" required><br><br>
    <button type="button" onclick="calculateBill()">Calculate Bill</button>
  </form>
  <div id="bill"></div>

  <script>
    function calculateBill() {
      var name = document.getElementById("cname").value.trim();
      var units = parseFloat(document.getElementById("units").value);
      if (name == "" || isNaN(units) || units < 0) {
        alert("Enter the name and a valid number of units");
        return;
      }
      var amount;
      if (units <= 100) amount = units * 5;
      else amount = 100 * 5 + (units - 100) * 8;

      var box = document.getElementById("bill");
      box.innerHTML = "<b>Consumer:</b> " + name + "<br><b>Units:</b> " + units +
                      "<br><b>Total Bill:</b> Rs. " + amount;
      box.style.display = "block";
    }
  </script>
</body>
</html>
```
<p>The first 100 units cost Rs.5 each and only the units above 100 cost Rs.8. E.g. 150 units = 100 × 5 + 50 × 8 = <b>Rs. 900</b>.</p>

=== RPQ Q15
```run html
<!DOCTYPE html>
<html>
<head>
  <script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
</head>
<body>
  <h3>Calorie Burn Calculator</h3>
  Weight (kg): <input type="number" id="weight"><br><br>
  Duration (min): <input type="number" id="duration"><br><br>
  <button id="calc">Calculate</button>
  <p id="out"></p>

  <script>
    $(document).ready(function () {
      $("#calc").click(function () {
        var w = parseFloat($("#weight").val());
        var d = parseFloat($("#duration").val());
        if (isNaN(w) || isNaN(d) || w <= 0 || d <= 0) {
          $("#out").text("Enter a valid weight and duration");
          return;
        }
        var cal = w * d * 0.1;
        var status;
        if (cal < 150) status = "Low Intensity";
        else if (cal <= 300) status = "Moderate Intensity";
        else status = "High Intensity";
        $("#out").html("Calories Burned: <b>" + cal.toFixed(1) + "</b><br>Status: <b>" + status + "</b>");
      });
    });
  </script>
</body>
</html>
```
<p>Calories = weight × duration × 0.1. E.g. 60 kg × 30 min × 0.1 = 180, which is Moderate; 70 kg × 60 min = 420, which is High.</p>

<ul><li><b>&lt;header&gt;</b>: the top section of a page or article (logo, title, menu).</li>
<li><b>&lt;nav&gt;</b>: a block of navigation links.</li></ul>
<p>Others: <code>&lt;main&gt;</code> (main content), <code>&lt;article&gt;</code>, <code>&lt;section&gt;</code>, <code>&lt;aside&gt;</code>, <code>&lt;footer&gt;</code>. They describe their <b>meaning</b>, which helps search engines and screen readers, unlike a plain <code>&lt;div&gt;</code>.</p>
