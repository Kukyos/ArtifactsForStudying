<h2>Internet, web and web technology</h2>
<ul>
<li>The <b>Internet</b> is the global network of connected computers. The <b>World Wide Web</b> is one service on it: pages linked by hyperlinks, fetched with <b>HTTP/HTTPS</b>, addressed by <b>URLs</b>.</li>
<li><b>How it works</b>: the browser (client) sends an HTTP <b>request</b> for a URL → DNS turns the domain into an IP address → the <b>web server</b> sends back a <b>response</b> (HTML, CSS, JS, images) → the browser renders it.</li>
<li><b>Web technology</b> = the languages and tools for building this: HTML (structure), CSS (presentation), JavaScript (behaviour) on the <b>client side</b>; Node.js, Express and databases like MongoDB on the <b>server side</b>.</li>
</ul>
<table class="tbl"><tr><th>Web page</th><th>Website</th><th>Web app</th></tr>
<tr><td>one HTML document</td><td>a collection of related pages under one domain</td><td>interactive software in the browser (Gmail, online banking)</td></tr></table>
<p><b>Static</b> sites send the same files to everyone; <b>dynamic</b> sites build pages per request from a database.</p>

<h2>HTML document structure</h2>
<p><b>HTML</b> (HyperText Markup Language) describes the <b>structure</b> of a page using <b>tags</b>. Current version: HTML5.</p>
```run html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello World!</h1>
  <p>This is a paragraph.</p>
</body>
</html>
```
<table class="tbl"><tr><th>Part</th><th>Role</th></tr>
<tr><td><code>&lt;!DOCTYPE html&gt;</code></td><td>tells the browser this is HTML5</td></tr>
<tr><td><code>&lt;html&gt;</code></td><td>root element; <code>lang</code> gives the language</td></tr>
<tr><td><code>&lt;head&gt;</code></td><td>information about the page, not shown: title, meta, links to CSS, scripts</td></tr>
<tr><td><code>&lt;meta&gt;</code></td><td>metadata: charset, viewport (mobile), description, keywords</td></tr>
<tr><td><code>&lt;title&gt;</code></td><td>text on the browser tab</td></tr>
<tr><td><code>&lt;body&gt;</code></td><td>everything visible</td></tr></table>
<p><b>Syntax</b>: an <b>element</b> = start tag + content + end tag: <code>&lt;p&gt;text&lt;/p&gt;</code>. <b>Attributes</b> go in the start tag as name="value": <code>&lt;img src="a.jpg" alt="..."&gt;</code>. <b>Empty</b> elements have no end tag: <code>&lt;br&gt;</code>, <code>&lt;hr&gt;</code>, <code>&lt;img&gt;</code>, <code>&lt;input&gt;</code>, <code>&lt;meta&gt;</code>. Comments: <code>&lt;!-- ... --&gt;</code>.</p>

<h2>Basic tags</h2>
<table class="tbl"><tr><th>Tag</th><th>Use</th></tr>
<tr><td><code>&lt;h1&gt;</code> … <code>&lt;h6&gt;</code></td><td>headings, h1 largest</td></tr>
<tr><td><code>&lt;p&gt;</code></td><td>paragraph</td></tr>
<tr><td><code>&lt;br&gt;</code>, <code>&lt;hr&gt;</code></td><td>line break, horizontal rule</td></tr>
<tr><td><code>&lt;img src alt width height&gt;</code></td><td>image; alt is shown if it fails and read by screen readers</td></tr>
<tr><td><code>&lt;div&gt;</code> / <code>&lt;span&gt;</code></td><td>generic block / inline container, used for styling</td></tr></table>
<p><b>Text formatting</b>: <code>&lt;b&gt;</code> bold, <code>&lt;strong&gt;</code> important (bold), <code>&lt;i&gt;</code> italic, <code>&lt;em&gt;</code> emphasis, <code>&lt;u&gt;</code> underline, <code>&lt;mark&gt;</code> highlight, <code>&lt;small&gt;</code>, <code>&lt;del&gt;</code> struck out, <code>&lt;ins&gt;</code> inserted, <code>&lt;sup&gt;</code> superscript (A²), <code>&lt;sub&gt;</code> subscript (H₂O), <code>&lt;pre&gt;</code> keeps spacing, <code>&lt;code&gt;</code>, <code>&lt;blockquote&gt;</code>.</p>

<h2>Block vs inline elements</h2>
<table class="tbl"><tr><th>Block</th><th>Inline</th></tr>
<tr><td>starts on a new line, takes full width</td><td>stays in the line, takes only its content's width</td></tr>
<tr><td>width/height/margins apply</td><td>width/height ignored</td></tr>
<tr><td><code>div, p, h1–h6, ul, ol, li, table, form, section</code></td><td><code>span, a, b, i, strong, img, input, label</code></td></tr></table>
<p>CSS <code>display</code> can change either (see 1.6).</p>

<h2>Semantic HTML5 elements</h2>
<p>Tags that say what their content <b>is</b>: <code>&lt;header&gt;</code>, <code>&lt;nav&gt;</code>, <code>&lt;main&gt;</code>, <code>&lt;section&gt;</code>, <code>&lt;article&gt;</code>, <code>&lt;aside&gt;</code>, <code>&lt;footer&gt;</code>, <code>&lt;figure&gt;</code> + <code>&lt;figcaption&gt;</code>. They help search engines and screen readers, and make code readable, unlike a plain <code>&lt;div&gt;</code>.</p>

<h2>CSS and how to add it</h2>
<p><b>CSS</b> (Cascading Style Sheets) controls presentation: colours, fonts, spacing, layout. A rule = <b>selector</b> + <b>declaration block</b>: <code>h1 { color: maroon; font-size: 24px; }</code>. Each declaration is <code>property: value;</code>.</p>
<table class="tbl"><tr><th>Method</th><th>How</th><th>Use</th></tr>
<tr><td>Inline</td><td><code>&lt;p style="color:red"&gt;</code></td><td>one element, quick tests</td></tr>
<tr><td>Internal (embedded)</td><td><code>&lt;style&gt;…&lt;/style&gt;</code> in the head</td><td>one page</td></tr>
<tr><td>External</td><td><code>&lt;link rel="stylesheet" href="style.css"&gt;</code></td><td>whole site, one file to change</td></tr></table>
<p><b>Cascade</b>: when rules conflict, the more <b>specific</b> selector wins (inline &gt; id &gt; class/attribute/pseudo-class &gt; element); for equal specificity, the <b>later</b> rule wins; <code>!important</code> overrides both. Inline beats internal and external styles.</p>

<h2>Selectors</h2>
<table class="tbl"><tr><th>Selector</th><th>Example</th><th>Selects</th></tr>
<tr><td>Universal</td><td><code>*</code></td><td>every element</td></tr>

<tr><td>Descendant</td><td><code>div p</code></td><td>p anywhere inside div</td></tr>

<h2>The box model</h2>
<p>Every element is a box: <b>content</b> → <b>padding</b> (inside the border, takes the background) → <b>border</b> → <b>margin</b> (outside, transparent).</p>
<p><b>Total width</b> = width + padding-left + padding-right + border-left + border-right (margin is extra space around it). E.g. width 350, padding 15, border 4 → 350 + 30 + 8 = <b>388px</b>. With <code>box-sizing: border-box</code>, <code>width</code> already includes padding and border.</p>
```run html
<style>
  .box { width: 200px; padding: 15px; border: 4px solid #c62828; margin: 20px; background: #fff8e1; }
</style>
<div class="box">content 200 + padding 30 + border 8 = 238px wide</div>
```
<p>Shorthand order is <b>top right bottom left</b> (clockwise): <code>margin: 10px 20px 10px 20px</code>; two values = top/bottom, left/right. <code>margin: 0 auto</code> centres a block with a width.</p>

<h2>Borders</h2>
<p><code>border: 2px solid black</code> = width, style, colour. Styles: <code>dotted, dashed, solid, double, groove, ridge, inset, outset, none, hidden</code>; four values set each side: <code>border-style: dotted dashed solid double</code>. <code>border-radius</code> rounds corners (50% = circle).</p>

<h2>Backgrounds and gradients</h2>
<ul>
<li><code>background-color</code>; <code>background-image: url("bg.jpg")</code></li>
<li><code>background-repeat</code>: repeat, repeat-x, repeat-y, no-repeat</li>
<li><code>background-size</code>: cover (fill, may crop), contain (fit whole image), or px/%</li>
<li><code>background-position</code>: center top, right bottom, …; <code>background-attachment: fixed</code> (stays when scrolling)</li>
<li>Gradients: <code>linear-gradient(to right, red, yellow)</code>, <code>radial-gradient(circle, white, blue)</code>, <code>repeating-linear-gradient(...)</code></li>
</ul>

<tr><td>color</td><td><code>red</code>, <code>#ff0000</code>, <code>rgb(255,0,0)</code>, <code>rgba(255,0,0,0.5)</code>, <code>hsl()</code></td></tr>

<h2>Transitions and animations</h2>
```run html
<style>
  .btn { background: #1565c0; color: #fff; padding: 10px 20px; border: none; transition: all 0.3s ease; }
  .btn:hover { background: #ffb300; color: #000; font-size: 18px; }
  .ball { width: 30px; height: 30px; border-radius: 50%; background: tomato; animation: move 2s linear infinite alternate; }
  @keyframes move { from { transform: translateX(0); } to { transform: translateX(250px); } }
</style>
<button class="btn">Hover me (transition)</button><br><br>
<div class="ball"></div>
```
<p><b>transition</b> animates a property change (e.g. on <code>:hover</code>) and reverses smoothly. <b>animation</b> + <b>@keyframes</b> runs on its own: name, duration, timing (linear/ease), iteration count (infinite), direction (alternate). <b>transform</b>: translate, rotate, scale.</p>

<h2>display, float and flexbox</h2>
<ul>
<li><code>display: block | inline | inline-block | none | flex | grid</code>. <code>none</code> removes the element (unlike <code>visibility: hidden</code>, which keeps its space).</li>
<li><code>float: left | right</code>: pushes an element to one side and lets text wrap around it; <code>clear: both</code> stops the wrapping. This was the old way to make columns and nav bars.</li>
<li><b>Flexbox</b> (one direction): <code>display: flex</code> on the parent; <code>flex-direction</code> (row/column), <code>justify-content</code> (main axis: flex-start, center, space-between, space-around), <code>align-items</code> (cross axis), <code>flex-wrap: wrap</code>, <code>gap</code>; children use <code>flex: 1</code> to share space.</li>
<li><b>Grid</b> (two directions): <code>display: grid; grid-template-columns: repeat(4, 1fr); gap: 10px;</code>; a child spans cells with <code>grid-column: span 2; grid-row: span 2</code>.</li>
</ul>

<h2>Navigation bar (a favourite 6-mark question)</h2>
```run html
<style>
  ul.nav { list-style: none; margin: 0; padding: 0; background: #333; display: flex; }
  ul.nav a { display: block; color: white; padding: 14px 24px; text-decoration: none; }
  ul.nav a:hover, ul.nav a.active { background: #777; }
</style>
<ul class="nav">
  <li><a href="#" class="active">Home</a></li><li><a href="#">News</a></li>
  <li><a href="#">Contact</a></li><li><a href="#">About</a></li>
</ul>
```
<p>Steps: links in a <code>&lt;ul&gt;</code> → remove bullets and padding → put items side by side (<code>display: flex</code> on the ul, or <code>float: left</code> on the li) → make each link a block with padding and no underline → add <code>:hover</code> and an <code>.active</code> class.</p>

<h2>Responsive design</h2>
<ul>
<li>The viewport meta tag: <code>&lt;meta name="viewport" content="width=device-width, initial-scale=1"&gt;</code>.</li>
<li><b>Media queries</b> apply rules only on some screens: <code>@media (max-width: 600px) { … }</code>. The widths where the layout changes are <b>breakpoints</b>. Also <code>@media (orientation: portrait|landscape)</code>.</li>
<li>Flexible sizes (%, fr, max-width: 100% on images) and flex/grid wrapping.</li>
</ul>
```run html
<style>
  .cols { display: grid; grid-template-columns: 1fr 1fr; gap: 8px; }
  .cols div { background: #e3f2fd; padding: 10px; }
  @media (max-width: 500px) { .cols { grid-template-columns: 1fr; } }
</style>
<div class="cols"><div>Column 1</div><div>Column 2</div></div>
<p>Two columns, one column below 500px.</p>
```

<h2>What Bootstrap is</h2>
<p><b>Bootstrap</b> is a free CSS (and JS) framework of ready-made classes for <b>responsive</b>, mobile-first pages: you add class names instead of writing CSS. Advantages: fast development, consistent look, responsive grid, works across browsers. Include it from a CDN:</p>
```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
```

<h2>Containers and the grid</h2>
<ul>
<li><code>.container</code>: responsive fixed-width, centred box; <code>.container-fluid</code>: always full width.</li>
<li>Grid: <code>.row</code> holds <code>.col-*</code> columns; each row has <b>12</b> units. <code>col-md-4</code> = 4/12 wide from the md breakpoint up (stacked on smaller screens). Breakpoints: sm 576, md 768, lg 992, xl 1200, xxl 1400 px. Plain <code>.col</code> = equal widths.</li>
</ul>
```run html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">
<div class="container mt-3">
  <div class="row">
    <div class="col-sm-4 bg-primary text-white p-2">col-sm-4</div>
    <div class="col-sm-8 bg-success text-white p-2">col-sm-8</div>
  </div>
  <button class="btn btn-primary mt-3">Primary</button>
  <button class="btn btn-outline-danger mt-3">Outline danger</button>
  <div class="alert alert-warning mt-3">alert alert-warning</div>
</div>
```
