<h2>What JavaScript is</h2>
<p><b>JavaScript</b> is the programming language of the web: it runs inside every browser (its <b>JavaScript engine</b>, e.g. V8 in Chrome) and makes pages interactive. It is interpreted/JIT-compiled, dynamically typed and event-driven, and with Node.js it also runs on servers. It is <b>not</b> related to Java apart from the name.</p>
<table class="tbl"><tr><th>Where</th><th>How</th></tr>
<tr><td>Internal</td><td><code>&lt;script&gt; … &lt;/script&gt;</code> in head or body (end of body is best, so the HTML exists first)</td></tr>
<tr><td>External</td><td><code>&lt;script src="app.js"&gt;&lt;/script&gt;</code></td></tr>
<tr><td>Inline event</td><td><code>&lt;button onclick="show()"&gt;</code></td></tr></table>

<h2>Showing output</h2>
<table class="tbl"><tr><th>Method</th><th>Where it appears</th></tr>
<tr><td><code>element.innerHTML = "…"</code></td><td>inside an HTML element (the usual way)</td></tr>
<tr><td><code>document.write("…")</code></td><td>into the page while loading (erases the page if called later)</td></tr>
<tr><td><code>alert("…")</code></td><td>pop-up box with OK</td></tr>
<tr><td><code>console.log("…")</code></td><td>browser console (F12) / Node terminal</td></tr>
<tr><td><code>input.value = …</code></td><td>inside a text box</td></tr></table>
<p><b>Pop-up boxes</b>: <code>alert(msg)</code>; <code>confirm(msg)</code> returns true/false; <code>prompt(msg, default)</code> returns the typed text or null.</p>

<h2>Variables and data types</h2>
<table class="tbl"><tr><th></th><th>var</th><th>let</th><th>const</th></tr>
<tr><td>Scope</td><td>function</td><td>block</td><td>block</td></tr>
<tr><td>Re-declare</td><td>yes</td><td>no</td><td>no</td></tr>
<tr><td>Re-assign</td><td>yes</td><td>yes</td><td>no</td></tr></table>
<p>Primitive types: <b>Number, String, Boolean, Undefined, Null, BigInt, Symbol</b>; reference type: <b>Object</b> (arrays and functions are objects). <code>typeof x</code> tells the type. Identifiers start with a letter, _ or $, and are case-sensitive.</p>

<h2>Operators and conversions</h2>
<ul>
<li>Arithmetic <code>+ - * / % **</code>; <code>++ --</code>; assignment <code>= += -=</code>.</li>
<li>Comparison: <code>==</code> compares after converting types (<code>"5" == 5</code> is true), <code>===</code> compares value <b>and</b> type (<code>"5" === 5</code> is false); <code>!= !== &gt; &lt; &gt;= &lt;=</code>.</li>
<li>Logical <code>&amp;&amp; || !</code>; ternary <code>cond ? a : b</code>.</li>
<li><code>+</code> with a string concatenates: <code>"2" + 3</code> = "23". Input box values are strings, so convert with <code>Number()</code>, <code>parseInt()</code> or <code>parseFloat()</code>. <b>NaN</b> = an invalid number; test with <code>isNaN()</code>.</li>
<li>Template literals: <code>`Hello ${name}`</code>.</li>
</ul>
```js
let a = "10", b = 5;
console.log(a + b);            // "105"  (string)
console.log(Number(a) + b);    // 15
console.log(parseInt("42px")); // 42
console.log("5" == 5, "5" === 5, typeof null, typeof [], isNaN("abc"));
```

<h2>Control flow</h2>
```js
// if / else if / else
if (marks >= 90) grade = "A";
else if (marks >= 75) grade = "B";
else grade = "C";

// switch
switch (op) {
  case "+": r = a + b; break;
  case "-": r = a - b; break;
  default: r = "invalid";
}

// loops
for (let i = 1; i <= 5; i++) { }
while (n > 0) { n--; }
do { } while (false);
for (const x of [1, 2, 3]) { }      // values of an array
for (const k in obj) { }            // keys of an object
```
<p><code>break</code> leaves a loop; <code>continue</code> skips to the next turn.</p>

<h2>Functions</h2>
<table class="tbl"><tr><th>Kind</th><th>Syntax</th><th>Notes</th></tr>
<tr><td>Declaration</td><td><code>function add(a, b) { return a + b; }</code></td><td>hoisted: can be called before it is written</td></tr>
<tr><td>Expression</td><td><code>const add = function (a, b) { return a + b; };</code></td><td>not hoisted</td></tr>

<p>Parameters can have defaults (<code>function f(x = 1)</code>). A <b>callback</b> is a function passed to another function to call later (event handlers, <code>setTimeout</code>, <code>forEach</code>). Built-in functions: <code>parseInt, isNaN, alert, Math.max, Math.round, Math.random…</code></p>
<p><b>Timers</b>: <code>setTimeout(fn, ms)</code> runs once after a delay; <code>setInterval(fn, ms)</code> repeats; stop with <code>clearTimeout / clearInterval</code>.</p>

```js
let marks = [80, 92, 75];
marks.push(88); marks.pop(); marks.unshift(70); marks.shift();
marks.length; marks.indexOf(92); marks.includes(75);
```

<h2>The standard programs</h2>
<p>All these are answered with a working page in the revision sets: palindrome, even/odd (<code>n % 2</code>), leap year (<code>(y%4==0 &amp;&amp; y%100!=0) || y%400==0</code>), largest, positive/negative/zero, prime (try divisors up to √n), factorial, Fibonacci, sum of an array, calculators, unit and currency converters, electricity bill slabs.</p>
<p><b>Pattern for "HTML page with embedded JavaScript" questions</b>: inputs with ids → a button with <code>onclick="calc()"</code> → in <code>calc()</code> read <code>.value</code>, convert with <code>parseFloat</code>, validate with <code>isNaN</code>, compute, write the result to an element's <code>innerHTML</code>.</p>

<h2>Synchronous vs asynchronous</h2>
<p><b>Synchronous</b> code runs line by line; each line waits for the previous one. <b>Asynchronous</b> code starts a slow job (timer, file, network, database) and continues; the result arrives later through a <b>callback</b>, a <b>Promise</b> (<code>.then()</code>) or <b>async/await</b>. This keeps pages and servers responsive.</p>
```js
console.log("1");
setTimeout(() => console.log("3: after the delay"), 0);
console.log("2");
// prints 1, 2, 3

async function load() {
  const res = await fetch("https://api.example.com/data");   // waits without blocking the page
  const data = await res.json();
}
```

<h2>Why validate in the browser</h2>
<p>Client-side validation gives instant feedback and stops obviously bad data before it is sent. It does <b>not</b> replace server-side checks (a user can bypass the browser).</p>
<h2>Two layers</h2>
<ul>
<li><b>HTML5 attributes</b>: <code>required, type="email", minlength, min/max, pattern</code> (see 1.3).</li>
<li><b>JavaScript</b>: <code>&lt;form onsubmit="return validate()"&gt;</code>. The function checks each field and returns <code>false</code> to block submission, showing a message next to the field.</li>
</ul>
<h2>Useful checks</h2>
<table class="tbl"><tr><th>Rule</th><th>Check</th></tr>
<tr><td>Not empty</td><td><code>v.trim() == ""</code></td></tr>
<tr><td>Length</td><td><code>v.length &lt; 6</code></td></tr>
<tr><td>Only letters</td><td><code>/^[A-Za-z]+$/.test(v)</code></td></tr>
<tr><td>Letters and digits</td><td><code>/^[A-Za-z0-9]+$/</code></td></tr>
<tr><td>Exactly 10 digits</td><td><code>/^[0-9]{10}$/</code></td></tr>
<tr><td>Email</td><td><code>/^[^\s@]+@[^\s@]+\.[^\s@]+$/</code></td></tr>
<tr><td>Has a digit</td><td><code>/[0-9]/.test(v)</code></td></tr>
<tr><td>Number in range</td><td><code>!isNaN(v) &amp;&amp; v &gt;= 0 &amp;&amp; v &lt;= 100</code></td></tr>
<tr><td>Passwords match</td><td><code>p1 === p2</code></td></tr></table>
<p>Regex reminders: <code>^</code> start, <code>$</code> end, <code>[...]</code> one of, <code>{n}</code> exactly n times, <code>+</code> one or more, <code>\d</code> a digit, <code>\s</code> a space; <code>regex.test(string)</code> returns true or false.</p>
```run html
<form onsubmit="return validate()">
  Name: <input id="n"> <span id="en" style="color:red"></span><br><br>
  Mobile: <input id="m"> <span id="em" style="color:red"></span><br><br>
  <input type="submit">
</form>
<p id="ok" style="color:green"></p>
<script>
  function validate() {
    var ok = true;
    var n = document.getElementById("n").value.trim(), m = document.getElementById("m").value.trim();
    document.getElementById("en").innerHTML = /^[A-Za-z ]{3,}$/.test(n) ? "" : (ok = false, "Letters only, 3+");
    document.getElementById("em").innerHTML = /^[0-9]{10}$/.test(m) ? "" : (ok = false, "10 digits");
    document.getElementById("ok").innerHTML = ok ? "Valid" : "";
    return false;   // demo: stay on the page
  }
</script>
```

<h2>JSON</h2>
<p><b>JSON</b> (JavaScript Object Notation) is a lightweight, text-based format for storing and exchanging data, language-independent but based on JS object syntax. Used by APIs, config files and MongoDB.</p>
<ul>
<li>Data in <b>name/value pairs</b>; keys must be in <b>double quotes</b>; objects in <code>{ }</code>, arrays in <code>[ ]</code>.</li>
<li>Value types: <b>string</b> (double quotes), <b>number</b>, <b>boolean</b>, <b>null</b>, <b>object</b>, <b>array</b>. No functions, dates, undefined or comments.</li>
<li>Why JSON: smaller and easier to read than XML, parsed directly into objects.</li>
</ul>
```js
{
  "name": "Ravi",
  "age": 20,
  "active": true,
  "middleName": null,
  "address": { "city": "Coimbatore", "pin": 641114 },
  "skills": ["HTML", "CSS", "JS"]
}
```
<h2>Converting</h2>
<table class="tbl"><tr><th>Direction</th><th>Method</th><th>Name</th></tr>
<tr><td>object → JSON text</td><td><code>JSON.stringify(obj)</code></td><td>serialization (to store or send)</td></tr>
<tr><td>JSON text → object</td><td><code>JSON.parse(text)</code></td><td>deserialization (to use the data)</td></tr></table>
```run html
<table id="t" border="1" cellpadding="4"><tr><th>Name</th><th>Marks</th></tr></table>
<script>
  var text = '[{"name":"Asha","marks":91},{"name":"John","marks":78}]';   // JSON text
  var list = JSON.parse(text);                                            // -> array of objects
  list.forEach(function (s) {
    document.getElementById("t").innerHTML += "<tr><td>" + s.name + "</td><td>" + s.marks + "</td></tr>";
  });
  console.log(JSON.stringify(list[0]));   // back to text
</script>
```
<p><b>JS object vs JSON</b>: an object literal is live code (keys may be unquoted, values may be functions); JSON is just a string in a strict format. Access parsed data with dot or bracket notation: <code>obj.address.city</code>, <code>obj.skills[1]</code>.</p>
