TP = 45, FN = 20, FP = 5, TN = 30, total = 100
Accuracy  = (TP + TN) / total = (45 + 30) / 100 = 0.75  (75 %)
Recall    = TP / (TP + FN) = 45 / 65 = 0.6923
Precision = TP / (TP + FP) = 45 / 50 = 0.9
F1-score  = 2 x P x R / (P + R) = 2 x 0.9 x 0.6923 / (0.9 + 0.6923) = 0.7826
Specificity = TN / (TN + FP) = 30 / 35 = 0.8571
