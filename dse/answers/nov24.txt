=== Nov24 Q22a
<h4>Working principle</h4>
<p>A decision tree is a supervised learning model (CART: classification and regression trees) shaped like a flow chart. Each <b>internal node</b> tests one attribute, each <b>branch</b> is an outcome of the test, and each <b>leaf</b> holds a class label. <b>ID3</b> (Iterative Dichotomiser 3) builds it top-down by repeatedly choosing the attribute that separates the classes best, measured by <b>entropy</b> and <b>information gain</b>:</p>
```gbox
Entropy(S) = - sum p_i log2 p_i            (0 = pure, 1 = maximum uncertainty for two equal classes)
Gain(S, A) = Entropy(S) - sum (|Sv| / |S|) x Entropy(Sv)
```
<h4>Steps of ID3</h4>
<ol><li>Compute the entropy of the whole set (the parent).</li><li>For every attribute compute the weighted entropy of its branches and its information gain.</li><li>Choose the attribute with the highest gain as the root (decision) node.</li><li>Make one branch for each value; repeat on each subset with the remaining attributes.</li><li>Stop when a subset is pure (one class), no attributes remain, or no data is left; label the leaf.</li></ol>

<table class="work"><tr><th>Metric</th><th>Formula</th><th>Meaning</th></tr>

=== Nov24 Q24a
<p>A <b>recommender system</b> is a tool that predicts what a user will like and suggests items (movies, products, songs, jobs) automatically, from preferences, past behaviour or similar users. It is an application of machine learning that <i>pushes</i> suggestions, unlike a search engine which <i>pulls</i> results for a query.</p>
<h4>Importance</h4>
<ul><li>Too much information: nobody can browse millions of items, so the system filters it.</li><li>Less effort and a better experience for the user; helps discover new items.</li><li>More sales, engagement and customer retention for the business (Netflix, Amazon, YouTube, LinkedIn).</li></ul>
<h4>Types</h4>
<table class="work"><tr><th>Type</th><th>Idea</th><th>Uses</th><th>Weakness</th></tr>
<tr><td><b>Content-based filtering</b></td><td>"more of what I liked": items similar to those the user liked</td><td>item features and the user's profile (TF-IDF, cosine similarity)</td><td>suggests only similar items</td></tr>
<tr><td><b>Collaborative filtering</b></td><td>"people like me liked this": similar users or similar items</td><td>the utility matrix of ratings (cosine / Pearson similarity)</td><td>cold start, sparsity</td></tr>
<tr><td><b>Hybrid</b></td><td>combine both</td><td>weighted, switching, mixed, cascade and other combinations</td><td>more complex</td></tr></table>
