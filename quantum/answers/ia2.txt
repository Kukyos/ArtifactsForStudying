=== IA2 Q4
```gbox
|ψ⟩ = cos(θ/2)|0⟩ + e^{iφ} sin(θ/2)|1⟩ ,   0 ≤ θ ≤ π ,  0 ≤ φ < 2π
Bloch vector (x, y, z) = (sinθ cosφ, sinθ sinφ, cosθ)
```
<ul>
<li><b>θ (polar angle)</b> is measured from the +z axis (|0⟩ at the north pole, |1⟩ at the south). It fixes the <b>measurement probabilities</b>: P(0) = cos²(θ/2), P(1) = sin²(θ/2).</li>
<li><b>φ (azimuthal angle)</b> is the angle around the z axis. It is the <b>relative phase</b> between |0⟩ and |1⟩. It does not affect Z-basis probabilities, but it changes interference and X/Y measurements (φ = 0 gives |+⟩, φ = π gives |−⟩, φ = π/2 gives |+i⟩).</li>
</ul>
<p>The global phase is dropped because it is unobservable, which is why two real angles are enough.</p>

=== IA2 Q5
<p><b>(a)</b> |ψ₀⟩ = <b>|01⟩</b> = |0⟩ ⊗ |1⟩.</p>
<p><b>(b)</b> H on the first qubit: <b>(|01⟩ + |11⟩)/√2</b> = |+⟩|1⟩.</p>

=== IA2 Q6
<p><b>(a)</b> |ψ₀⟩ = <b>|00⟩</b>.</p>
<p><b>(b)</b> H on the first qubit: <b>(|00⟩ + |10⟩)/√2</b>.</p>
<p><b>(c)</b> S on the first qubit (|1⟩ → i|1⟩): <b>(|00⟩ + i|10⟩)/√2</b>.</p>
<p><b>(d)</b> CNOT: |10⟩ → |11⟩, giving <b>(|00⟩ + i|11⟩)/√2</b>, which is entangled.</p>
<p><b>Role of the phase:</b> the S gate's i is carried into the entangled state as a <b>relative phase</b> between |00⟩ and |11⟩. It does not change the Z-basis statistics (still 50 % 00 and 50 % 11, always correlated). But it makes this a different state from |Φ⁺⟩: measured in the X or Y basis, or decoded with a Bell measurement, it behaves differently. That is how phases carry information in superdense coding and teleportation.</p>

=== IA2 Q7
<p>The circuit is H on q0, then CNOT q0→q1. Starting from |00⟩:</p>
<ol class="steps">
<li>H on q0: (|00⟩ + |10⟩)/√2.</li>
<li>CNOT: |10⟩ → |11⟩, giving <b>(|00⟩ + |11⟩)/√2 = |Φ⁺⟩</b>, the Bell state.</li>
</ol>
<p>This is the standard <b>Bell-state generator</b>. The output is maximally entangled: 00 or 11, each with probability 1/2. With other inputs it gives the other Bell states: |01⟩ → Ψ⁺, |10⟩ → Φ⁻, |11⟩ → Ψ⁻.</p>
